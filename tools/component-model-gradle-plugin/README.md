# KRWA Component Model Gradle Plugin

`uk.shusek.krwa.component-model` is the Gradle integration layer for KRWA
Component Model tooling. It keeps WIT binding generation and component packaging
owned by the KRWA toolchain, while host applications can keep their own SDK and
manifest contracts.

```kotlin
plugins {
    id("uk.shusek.krwa.component-model") version "0.3.0-rc.12"
}

krwaComponentModel {
    // Use witFile for a single-file contract, or witPackageDirectory for a full WIT package graph.
    witFile.set(layout.projectDirectory.file("plugin.wit"))
    bindingsPackage.set("example.generated")
    bindingsSourceSetName.set("wasmWasiMain")
    bindingsOutputDirectory.set(layout.buildDirectory.dir("generated/wit-bindings/wasmWasiMain/kotlin"))
    bindingsOutputFileName.set("PluginBindings.kt")
    bindingsSplitFiles.set(true)
    autoWireKotlinSourceSet.set(true)
    pluginHelpers.set(true)

    componentWorld.set("plugin")
    componentCoreModuleFile.set(layout.buildDirectory.file("compileSync/wasmWasi/main/productionExecutable/kotlin/app.wasm"))
    componentOutputFile.set(layout.buildDirectory.file("component/plugin.component.wasm"))
    asyncCallback.set(true)
}
```

Registered tasks are listed with `./gradlew tasks --group krwa`:

- `generateKrwaKotlinWitBindings` runs `KotlinWitBindgen`.
- `packageKrwaComponent` runs `WasmComponentPackager`.

For Kotlin Multiplatform projects, `autoWireKotlinSourceSet` adds
`bindingsOutputDirectory` to the configured `bindingsSourceSetName` and wires
Kotlin compile tasks to `generateKrwaKotlinWitBindings`. This keeps guest-only
bindings in `wasmWasiMain` and host/shared bindings in `jvmMain`, `commonMain`,
or a custom test source set without hand-written `kotlin.srcDir(...)` wiring.
Set `bindingsSplitFiles` to generate one Kotlin file per WIT interface/world plus
small runtime/guest adapter files under `bindingsOutputDirectory`. Leave it
disabled to preserve the legacy single `bindingsOutputFile` output.

Both generation and packaging can receive a full WIT package directory:

```kotlin
krwaComponentModel {
    witPackageDirectory.set(layout.projectDirectory.dir("wit"))
    componentWitPackageDirectory.set(layout.projectDirectory.dir("wit"))
}
```

The plugin intentionally does not define an application SDK. Projects such as
Suvio should keep their WIT files, manifest versions, and compatibility policy
in their own SDK module, then use this plugin as the build-time KRWA toolchain.
Snapshots are published to the KRWA GitHub Pages Maven repository:

```kotlin
pluginManagement {
    repositories {
        gradlePluginPortal()
        mavenCentral()
        maven("https://shusek.github.io/kotlin-runtime-web-assembly/maven")
    }
}
```

Pin the plugin version to the SDK/WIT contract generated by the host project.
